# Consulta DDD

Aplicacao mobile em React Native com TypeScript para consultar UF e cidades a partir de um codigo DDD usando a Brasil API.

## Como executar

```bash
npm install
npm start
```

## Tecnologias

- React Native com Expo
- TypeScript
- Hooks `useState` e `useEffect`
- Consumo de API RESTful com `fetch`
